# DYNEX Website

Premium static landing page for DYNEX, themed around the supplied blue/black DYNEX logo.

## Deploy

This is a plain HTML/CSS/JS site. Upload the contents to Replit, Cloudflare Pages, Netlify, or any static host.

## Add-to-Discord link

Open `script.js` and replace `YOUR_CLIENT_ID` with the Discord Application Client ID. The website does not contain or require your bot token.
